01 — Inizia

Scarica e installa.

Scegli il file del tuo sistema, installalo e supera l'avviso del primo avvio.

macOS.dmg · Apple Silicon e Intel WindowsInstaller .exe · 64 bit Linux.tar.gz · x86_64 AndroidL'APK ha un capitolo suo

Templar Wallet è un'alpha e lavora solo su Bitcoin testnet e Liquid testnet. Le monete non hanno valore.

Cosa serve

SistemaMinimoServe anche
macOS10.15 Catalina o successivo, Apple Silicon o IntelNiente
Windows10 (versione 1809 o successiva) o 11, 64 bit (x64)Di norma niente
Linuxx86_64: Ubuntu 22.04 o successiva, Debian 12 o successivaGTK 3, libudev e libEGL: i desktop li hanno già

Per sincronizzare e inviare serve internet: l'app si collega in TLS ai server testnet pubblici di Blockstream. Aprire un wallet e preparare una transazione funziona anche offline.

Non servono account, chiavi API o un nodo tuo.

La cifratura del vault usa molta memoria: quando scrivi la password servono almeno 2 GB di RAM libera.

Attenzione. Le build non sono firmate con un certificato Apple o Microsoft, quindi al primo avvio macOS e Windows mostrano un avviso. È previsto: qui sotto trovi come superarlo. Prima, verifica il file.

macOS

L'app non è notarizzata da Apple, quindi macOS la blocca con «Apple non è riuscita a verificare…» o dice che è «danneggiata». La causa è la quarantena che il browser mette sui file scaricati.

Metodo 1, dal Terminale. Toglie la quarantena e funziona sempre, anche su macOS 26 Tahoe.

  1. Apri il Terminale. Cmd+Spazio, scrivi «Terminale», Invio.
  2. Sblocca il .dmg. Scrivi xattr -d com.apple.quarantine e uno spazio, trascina il .dmg nella finestra e premi Invio. Se risponde No such xattr, va bene lo stesso.
  3. Installa. Apri il .dmg, trascina Templar Wallet in Applicazioni ed espelli il disco.
  4. Sblocca l'app e aprila con questi due comandi. La -r serve: la quarantena sta anche sui file dentro l'app. 
    xattr -r -d com.apple.quarantine "/Applications/Templar Wallet.app"
open "/Applications/Templar Wallet.app"

Metodo 2, fino a macOS 15 Sequoia. Trascina l'app in Applicazioni e aprila: macOS la blocca. Chiudi l'avviso con Fine. Poi Impostazioni di Sistema → Privacy e sicurezza → Apri comunque, e conferma con la password del Mac o Touch ID.

Il tasto destro → Apri funziona solo fino a macOS 14 Sonoma. Su Tahoe, se Apri comunque non compare o l'app risulta «danneggiata», usa il Metodo 1.

Hai anche lo script install-macos.sh? Mettilo accanto al .dmg e lancia bash install-macos.sh: fa il Metodo 1 da solo. Se trova una versione precedente la sostituisce, e non tocca i dati dei wallet.

La prima volta che usi Scan QR, macOS chiede l'accesso alla fotocamera. Concedilo, o l'anteprima resta nera.

Windows

Il file consigliato è l'installer. La procedura guidata è in inglese.

  1. Avvia il setup. SmartScreen dice «Windows ha protetto il PC»: scegli Ulteriori informazioni → Esegui comunque.
  2. Scegli per chi. Se te lo chiede: Install for all users (serve un amministratore) o Install for me only.
  3. Select Destination Location. È la cartella del programma. Ogni aggiornamento la sostituisce.
  4. Select Wallet Data Location. Qui stanno wallet, vault cifrato e cache. La proposta è %APPDATA%\templar_wallet. Deve stare fuori dalla cartella del programma: gli aggiornamenti non la toccano e resta anche se disinstalli.
  5. Installa. L'icona sul desktop è facoltativa e spenta di serie (Create a desktop shortcut). Poi Install.

Nota. L'app legge la cartella dati al primo avvio e poi la ricorda. Se reinstalli e scegli un'altra cartella, i wallet che hai già non si spostano. La cartella in uso la vedi in Settings → Security → Storage.

L'installer non aggiunge servizi né driver, e niente parte con Windows. Solo l'installer, non lo zip, registra i link templar:// del protocollo.

Versione portabile (zip). Tasto destro sullo zip → Estrai tutto… in una cartella vera. Non avviare l'app dall'anteprima dello zip: accanto all'eseguibile servono la cartella data\ e le DLL. Poi doppio clic su templar_wallet.exe. SmartScreen avvisa allo stesso modo. I dati vanno in %APPDATA%\templar_wallet.

Manca VCRUNTIME140.dll o MSVCP140.dll? Installa il Visual C++ Redistributable x64 e riprova.

Linux

Estrai l'archivio e avvia il programma. Al posto dei nomi tra < > metti quelli veri.

tar xzf <file scaricato>.tar.gz
./<cartella estratta>/templar_wallet

La cartella contiene tutto. Spostala dove vuoi, ma tienila intera. Se mancano librerie, su Debian e Ubuntu:

sudo apt install libgtk-3-0 libudev1 libegl1

Su Fedora:

sudo dnf install gtk3 systemd-libs libglvnd-egl

L'errore version `GLIBC_2.xx' not found vuol dire che la distribuzione è troppo vecchia. Segnalacelo, con il nome della distribuzione.

Voce nel menu, facoltativa. Registra anche i link templar://. Apri il terminale dentro la cartella estratta e lancia:

mkdir -p ~/.local/share/applications
sed -e "s|^Exec=.*|Exec=$PWD/templar_wallet %u|" \
    -e "s|^Icon=.*|Icon=$PWD/templar_wallet.png|" \
    dev.templarwallet.templar_wallet.desktop \
    > ~/.local/share/applications/dev.templarwallet.templar_wallet.desktop
update-desktop-database ~/.local/share/applications

Se sposti la cartella, rilancia i comandi dalla nuova posizione.

Aggiornare e disinstallare

Per aggiornare, installa la versione nuova sopra la vecchia. I dati e i wallet restano.

SistemaAggiornareDisinstallare
macOSRipeti il Metodo 1, o lo scriptTrascina l'app nel Cestino
WindowsLancia il nuovo installer. Portabile: estrai in una cartella nuovaImpostazioni → App → App installate → Templar Wallet → Disinstalla. Portabile: cancella la cartella
LinuxEstrai la cartella nuova, cancella la vecchiaCancella la cartella e, se l'hai creato, il file .desktop

Attenzione. Prima di ogni aggiornamento, controlla di avere la frase di recupero su carta.

Sul computer la cartella dati resta anche dopo la disinstallazione. Dove si trova e come cancellarla: Problemi e segnalazioni.

02 — Inizia

Verifica il download.

Un'impronta SHA-256 ti dice se il file che hai è quello pubblicato.

Le impronte stanno in SHA256SUMS.txt, allegato a ogni rilascio, una riga per ogni file. Il pacchetto dei tester lo contiene. Se accanto al tuo download c'è, controllalo prima di installare. Se l'impronta non coincide, il file è corrotto o non è quello pubblicato.

  1. Metti i file insieme. Salva SHA256SUMS.txt nella cartella del file scaricato.
  2. Apri un terminale in quella cartella. Il Terminale su macOS e Linux, PowerShell su Windows.
  3. Lancia il comando del tuo sistema, qui sotto.

macOS e Linux:

shasum -a 256 -c SHA256SUMS.txt

Su Linux va bene anche sha256sum -c SHA256SUMS.txt. Accanto al tuo file deve comparire OK. Le righe dei file che non hai scaricato danno errore: ignorale.

Windows, in PowerShell:

Get-FileHash .\<nome del file> -Algorithm SHA256

Confronta il risultato con la riga di quel file in SHA256SUMS.txt. Maiuscole e minuscole non contano.

L'APK per Android puoi controllarlo allo stesso modo su un computer, prima di passarlo al telefono.

Attenzione. Oggi l'elenco delle impronte non è firmato, né con GPG né in altro modo. L'impronta dice che il file è uguale a quello dell'elenco. Non dice chi ha scritto l'elenco.

Nota. Le build non hanno un certificato. L'app per macOS è firmata solo ad-hoc e non è notarizzata. L'installer Windows non ha la firma Authenticode. L'APK è firmato in modalità debug e non passa dal Play Store. Per questo il sistema avvisa al primo avvio. L'avviso non vuol dire che il file sia stato manomesso: per quello c'è l'impronta. Come superarlo: Scarica e installa e Su Android.

Quale versione hai

La versione giusta la mostrano l'installer di Windows, le informazioni app di Android e il Finder. Il Finder la scrive corta: per esempio 0.1.0.15 sta per 0.1.0-alpha.15.

Non guardare Settings → About: per un errore noto mostra sempre v0.1.0-alpha.1.

03 — Inizia

Su Android.

Come installare Templar Wallet sul telefono e cosa cambia rispetto al computer.

In lavorazione. L'app per Android è un'alpha. Funziona solo su testnet, come quella per computer.

Serve Android 7.0 o successivo. L'APK si installa a mano, fuori dal Play Store.

Scarica l'APKarm64 · Android 7.0 o successivo

Su telefono o tablet scegli sempre l'APK arm64. Quello x86_64 serve solo agli emulatori Android su PC Intel o AMD. Non esiste una versione a 32 bit.

Installare l'APK

  1. Porta l'APK sul telefono. Scaricalo dal telefono, oppure copialo con il cavo, un cloud o una chat.
  2. Aprilo. Tocca il file nell'app File, o nella notifica del download.
  3. Consenti l'installazione. La prima volta Android la blocca. Tocca Impostazioni, attiva Consenti da questa fonte e torna indietro.
  4. Installa. Tocca Installa. Se Google Play Protect avvisa, scegli Altri dettagli → Installa comunque.
  5. Apri l'app. Trovi Templar Wallet nel cassetto delle app.

L'avviso arriva perché l'APK non viene dal Play Store.

Cosa cambia sul telefono

FunzioneSu Android
NavigazioneBarra in basso: Dashboard · Activity · UTXOs · Liquid · Settings. Send e Receive stanno nella Dashboard, Wallet info in Settings. Liquid compare se il wallet ha Liquid, con le schede Assets · LiquiDEX · Peg.
FotocameraLegge tutti i QR: indirizzi, chiavi, transazioni. La prima volta Android chiede il permesso.
Hardware walletNiente USB. Si collegano solo via QR, per esempio SeedSigner o Jade in modalità QR. Un Jade via QR gestisce solo Bitcoin. Vedi Hardware wallet.
Co-firma multisigIl telefono firma e restituisce la copia firmata. Non la trasmette in rete: lo fa chi ha avviato la transazione.

Schermate protetteLa frase di recupero e la chiave privata non si possono catturare con uno screenshot.

Attenzione. I wallet stanno nella memoria privata dell'app e non finiscono nei backup del telefono. Se disinstalli l'app o ne cancelli i dati, i wallet spariscono. Tieni la frase di recupero su carta. Per aggiornare, installa il nuovo APK sopra il vecchio: i wallet restano.

Se qualcosa non va

  • «App non installata». Sul telefono c'è già una versione firmata in modo diverso. Controlla di avere la frase di recupero su carta, poi disinstalla e riprova.
  • «Camera unavailable». Tocca Try again, oppure Open app settings e consenti la fotocamera.
  • Segnalare un problema. Su Android il log non si può esportare. Manda screenshot, i passi fatti e l'ora circa. Altro in Problemi.

04 — Inizia

Il primo wallet.

Crea un wallet, scrivi la frase su carta e ricevi le prime monete di test.

L'app è in inglese. Qui trovi pulsanti e schermate scritti come li vedi.

Al primo avvio scegli Create new wallet per crearne uno nuovo. Con Restore an existing wallet ne ripristini uno dalla frase di recupero.

Creare un wallet

Per un wallet a una chiave su questo dispositivo i passi sono 8. Sono 7 se la password dell'app esiste già.

  1. What kind of wallet? One key è la strada più semplice. Several keys must agree (multisig) chiede più firme: vedi Multisig. Custom rules (policy) è segnato Coming soon e non si può scegliere. Somewhere else — just watch it segue un wallet che hai altrove: mostra saldo e storico, non può spendere.
  2. Where do your keys live? On this computer (sul telefono On this device) oppure On a hardware wallet: vedi Hardware wallet.
  3. Which coins? Bitcoin + Liquid aggiunge Liquid dalla stessa frase, senza niente in più da scrivere. Oppure Bitcoin only. Come rete si può scegliere solo Testnet.
  4. Protect this app with a password. Solo la prima volta. Almeno 8 caratteri, scritti due volte. Poi Start setup.
  5. Name & seed length. Dai un nome al wallet. 24 words è la scelta consigliata. 12 words è più comoda da copiare a mano.
  6. Back up your seed. Le parole compaiono una volta sola, numerate. Scrivile su carta.
  7. Verify your backup. L'app ti chiede tre parole. Poi Confirm & Finish.
  8. Wallet created. Scegli Get receive address o Open Wallet.

La password dell'app

Serve quando la frase di recupero resta su questo dispositivo, e per ogni multisig. Cifra i dati salvati (Argon2id + XChaCha20-Poly1305). L'app la chiede a ogni avvio e prima delle azioni delicate. Una sola password vale per tutti i wallet.

Ne fanno a meno solo i wallet con la chiave su un hardware wallet e quelli watch-only, con Skip — don't encrypt wallet storage. Non è la passphrase BIP39 e non fa parte della frase di recupero.

Attenzione. Se perdi la password, l'app non riapre i wallet salvati qui. Solo la frase di 12 o 24 parole scritta su carta li riporta indietro. In questa alpha la password non si può cambiare né togliere. Altro in Sicurezza.

La frase di recupero

Le 12 o 24 parole sono il wallet. Chi le ha può spendere.

  • Su carta, non su uno schermo. Niente foto, file o chat.
  • Nell'ordine esatto. Numera le parole mentre le scrivi.
  • Due copie in due posti diversi.
  • Mai dettarla a nessuno. Chi te la chiede sta rubando.

Le prime monete di test

Apri Receive, copia l'indirizzo e incollalo in un faucet. Le monete di test sono gratuite e non hanno valore.

  • Bitcoin testnet: coinfaucet.eu/en/btc-testnet
  • Liquid testnet: liquidtestnet.com/faucet o faucet.vulpem.com

La prima sincronizzazione Liquid è una scansione completa. Può volerci qualche minuto.

Aprire, cambiare, bloccare

Con almeno un wallet, l'app si apre sull'elenco Your Wallets. Ogni scheda dice tipo e monete, per esempio Software · BTC + Liquid. Un multisig mostra la soglia, per esempio 2-of-3. Da qui partono anche Restore e New Wallet.

  • Sbloccare. Se compare Unlock wallet storage, scrivi la password in Vault passphrase e premi Unlock. Se li hai attivati, puoi usare Use Touch ID sul Mac o Use fingerprint su Android.
  • Cambiare wallet. Sul computer, la doppia freccia accanto al nome del wallet riporta all'elenco. Sul telefono tocca il nome del wallet in alto.
  • Bloccare. Sul computer Settings → Security → Lock now, sul telefono Settings → Lock now. Sul computer c'è anche il lucchetto in fondo alla barra laterale e nell'elenco dei wallet.

Ripristinare un wallet

  1. Apri Restore Wallet. Dal benvenuto con Restore an existing wallet, dall'elenco con Restore.
  2. Seed phrase. Scrivi le 12 o 24 parole, separate da uno spazio.
  3. Wallet name e Coins. Dai un nome e scegli Bitcoin + Liquid o Bitcoin only.
  4. Restore Wallet. Premi il pulsante.

Se la password dell'app non esiste ancora, prima si apre Encrypt wallet storage per crearla.

Attenzione. Scrivi la frase solo su un dispositivo di cui ti fidi.

05 — Usa il wallet

Ricevere e inviare.

Dove trovi le cose, come dai un indirizzo e come mandi una transazione.

La finestra

Su computer, a sinistra c'è la barra laterale. In cima trovi il wallet aperto: la doppia freccia torna all'elenco dei wallet.

  • WALLET: Dashboard, Send, Receive, Activity, UTXOs. Un wallet watch-only non ha Send: può solo guardare.
  • LIQUID: Liquid, LiquiDEX, Peg. Compare solo se il wallet ha Liquid. Peg compare solo se il wallet ha anche Bitcoin.
  • SYSTEM: Wallet Info, Settings.

In fondo alla barra un pallino dice lo stato: Synced, Partial sync, Sync Error o Idle. Sotto ci sono Sync now e il tema chiaro o scuro. Quando l'archivio è aperto c'è anche il lucchetto Lock wallet storage, che lo richiude subito.

La Dashboard riassume il wallet: valore totale, grafico, filtri All / BTC / Liquid, valuta o sats, le schede Bitcoin e Liquid. L'occhio nasconde gli importi. Send e Receive stanno sotto il grafico. In alto a destra il badge TESTNET ti ricorda la rete.

Ricevere

Receive ti dà un indirizzo Bitcoin nuovo (Native SegWit), il suo QR e Copy address.

  • New address ne crea un altro. Usane uno per pagamento: riusare un indirizzo lega i pagamenti tra loro.
  • Previous addresses mostra gli ultimi 8. Show all apre l'elenco completo.
  • Con il selettore in alto passi a Liquid. L'indirizzo è confidential: importi e asset restano nascosti sulla catena, e puoi riusarlo.
  • Request an amount aggiunge un importo e una nota facoltativa. QR e link diventano un link di pagamento (BIP21) e il pulsante diventa Copy payment link. Share lo manda con le app del sistema.

Dopo aver incollato l'indirizzo altrove, controlla i primi e gli ultimi caratteri. Quando il pagamento è confermato, puoi dargli un nome con Tag nella schermata UTXOs.

Inviare

Send ha sei passi, uno per scelta. Niente viene firmato prima dell'ultimo.

  1. Type. Standard transaction crea una transazione nuova. In un multisig si chiama Create a partial transaction. Cosign a transaction aggiunge la tua firma a una transazione preparata da altri: vedi Multisig.
  2. Network. Bitcoin o Liquid Network, con il saldo disponibile. Su Liquid scegli anche l'asset.
  3. Inputs. Automatic lascia scegliere al wallet. Manual coin control ti fa scegliere quali monete spendere. Su Liquid la scelta è solo automatica.
  4. Outputs. Indirizzo e importo. Dal campo indirizzo puoi scansionare un QR (su macOS e Android), incollare o usare un indirizzo di questo wallet. MAX spende tutto, tolta la commissione. La freccia accanto all'unità passa alla valuta. Add output aggiunge un destinatario. Un link di pagamento compila indirizzo e importo insieme.
  5. Fee. Slow, Normal, Fast o Custom (minimo 0,1 sat/vB). Su Liquid la commissione è fissa e minima: non c'è niente da impostare.
  6. Review. Uno schema mostra ingressi e uscite: destinatario, resto (CHANGE, torna a te) e commissione, poi il totale. Nel caso più comune, Bitcoin con la chiave salvata nell'app, Review & sign apre Review transaction. Sign chiede la password dell'app, o Touch ID sul Mac se l'hai attivato. Broadcast manda la transazione in rete.

Negli altri casi il pulsante per firmare cambia. Su Liquid è Sign & send. In un multisig è Sign & continue: se servono altre firme, passi la transazione ai cofirmatari (vedi Multisig). Con un hardware wallet è Sign on device, con un dispositivo air-gap Export PSBT.

Limiti. Su Bitcoin il wallet rifiuta una commissione più alta sia di 0,01 BTC sia del 10% di quanto sposta la transazione. Ogni transazione Bitcoin segnala replace-by-fee, ma per ora non c'è una schermata per alzare la commissione.

Attenzione. Prima di firmare, controlla l'indirizzo carattere per carattere. È l'ultima occasione per scoprire un errore di battitura o un malware che cambia l'indirizzo copiato negli appunti.

06 — Usa il wallet

Attività, monete e Wallet Info.

Lo storico, le singole monete e le chiavi pubbliche del wallet.

Activity

Activity mette insieme lo storico Bitcoin e Liquid, diviso per giorno, con conferme, nota e controvalore. Puoi cercare per txid o per nota. I filtri All / Bitcoin / Liquid isolano una catena. L'occhio nasconde gli importi.

Apri una riga per il dettaglio: da lì copi il txid o premi View on Explorer.

UTXOs

Un wallet non ha «un saldo». Ha monete separate, gli UTXO. Vederle una per una ti fa scegliere quali spendere.

Ogni riquadro è una moneta, con la sua taglia e la sua quota del totale. In alto vedi quante monete hai, quante ne hai selezionate e il totale selezionato. A destra ci sono Consolidate e le viste Notes / List.

TagliaCosa vuol dire
DUSTFino a 546 sats. Spenderla può costare più di quanto vale.
SMALLMeno del 5% del saldo.
BIGTra il 5% e il 25% del saldo.
HUGEOltre il 25% del saldo.
WHALE1 BTC o più.

Un token non è mai DUST o WHALE per la sua quantità: 500 unità di una stablecoin non sono 500 sats.

  • Una moneta appena arrivata è grigia, con la scritta Incoming. Non puoi selezionarla finché un blocco non la include.
  • La i apre i dettagli: importo, taglia, conferme, outpoint, indirizzo e Open in explorer.
  • Seleziona una o più monete e premi Tag per scrivere una nota. La nota ricompare quando scegli le monete da spendere.
  • Consolidate unisce più monete in una. Funziona solo su Bitcoin e con almeno 2 monete. Costa una transazione, ma rende più economiche quelle dopo.

Wallet Info

In alto c'è l'identità del wallet: nome, rete, master fingerprint, percorso di derivazione e tipo di script. Sotto ci sono i descriptor pubblici. Ogni riga ha un pulsante per copiare e uno per il QR.

  • For other apps: Copy descriptor bundle, Export JSON e Show QR esportano una copia watch-only per un altro programma. L'app nomina Sparrow, Specter, BlueWallet, Jade e SeedSigner.
  • Se il wallet non ha ancora Liquid, la scheda Liquid Network offre Enable Liquid. Con un Jade il pulsante è Add Liquid from my Jade.
  • L'XPUB m/84'/1'/0' è la chiave del wallet a firma singola. Non è una chiave da cofirmatario.
  • Per entrare nel multisig di qualcun altro, un wallet a firma singola ha la scheda Use this wallet as a cosigner: la chiave Bitcoin (BIP48) e la chiave Liquid (BIP87), ognuna con copia e QR. Se le chiavi stanno su un hardware wallet, le leggi dal dispositivo nella procedura multisig. Vedi Multisig.

Nota. Un xpub non permette di spendere, ma mostra tutti gli indirizzi e tutto lo storico del wallet. Condividilo solo con chi ha motivo di vederli.

07 — Usa il wallet

Sicurezza e impostazioni.

Come si blocca il wallet, cosa c'è in Settings e le abitudini che proteggono la frase.

Bloccare e sbloccare

Quando l'archivio è bloccato compare Unlock wallet storage. Scrivi la password dell'app e premi Unlock. Se hai attivato l'impronta, puoi usare anche Use Touch ID sul Mac o Use fingerprint su Android.

Per bloccare: il lucchetto in fondo alla barra laterale, oppure Lock now in Settings. Il blocco cancella dalla memoria le chiavi decifrate.

Auto-lock blocca da solo. Sul telefono conta il tempo in secondo piano. Su computer conta anche il tempo senza tastiera né mouse. Quando scatta, torni all'elenco dei wallet e serve di nuovo la password. Funziona solo se la password dell'app è impostata.

Su computer Lock now e Auto-lock sono in Settings → Security. Sul telefono sono nell'elenco di Settings.

Auto-lockQuando blocca
ImmediatelyAppena l'app esce dallo schermo.

Multisig e co-firma.

Un multisig M-su-N spende solo quando M chiavi diverse hanno firmato.

Le chiavi possono stare su dispositivi o persone diverse. Templar prepara la transazione, raccoglie le firme e la trasmette.

Creare il wallet

  1. Tipo. What kind of wallet? → Several keys must agree (multisig), poi Which coins?.
  2. Password dell'app. Se non c'è ancora, l'app la chiede. Per un multisig è obbligatoria.
  3. Soglia. In Choose your threshold scegli il nome, le firme richieste (M) e le chiavi totali (N, da 2 a 9). Con I hold one of these keys here acceso, l'app crea qui la tua chiave e te ne fa fare il backup. Spento, importi tutte le chiavi.
  4. Chiavi. In Import the keys ogni chiave può avere nome, icona e colore. Poi scegli da dove arriva.
  5. Crea. Review & create → Create Wallet.
ProvenienzaQuando
Paste or scan a keyLa xpub di un cofirmatario, da un altro software o da un dispositivo air-gap (SeedSigner, Jade in modalità QR e sbloccato). Poi Done with this key.
App walletUn wallet software già in questa app. Spunta Sign with this key from this app per firmare da qui.
USB deviceUn hardware wallet collegato: Read xpub from device. Solo su computer.
New keyUna chiave nuova, con il suo backup. Firma da qui.
Seed phraseUna frase che hai già. Firma da qui.

Ogni chiave viene controllata prima dell'uso. Una chiave con percorso mainnet viene rifiutata.

In Dashboard la scheda Keys mostra un anello, una fetta per chiave nel suo colore, e la regola Any M of N keys can sign.

Bitcoin e Liquid insieme

Un solo wallet, due catene. Ogni cofirmatario dà due chiavi: quella Bitcoin (BIP48) e la Cosigner Liquid key (BIP87). Se la chiave è in questa app o su un Jade, l'app legge da sola anche la seconda.

  • Una chiave Ledger, Trezor, Coldcard o KeepKey rende il wallet solo Bitcoin. Tra gli hardware wallet, solo il Jade firma su Liquid.
  • Un multisig solo Bitcoin non si allarga a Liquid. Ricrealo con le stesse chiavi: stessi indirizzi Bitcoin, stessi fondi.
  • Le stesse chiavi danno lo stesso wallet Liquid su ogni dispositivo.

Per entrare nel multisig di un altro, apri un tuo wallet a chiave singola: Wallet info → Use this wallet as a cosigner. Ci sono le due chiavi, ognuna con copia e QR. Si possono condividere: nessuna delle due può spendere.

Per seguire un multisig senza firmare: Somewhere else — just watch it → Build from cosigner keys.

Avviare una spesa

  1. Prepara. Send → Create a partial transaction, poi firma con la tua chiave.
  2. Fai girare. Si apre Co-signatures needed. Il grafico SIGNATURE QUORUM ha una fetta per chiave e dice chi ha già firmato. La transazione esce come QR animato, con Copy PSBT o con Save .psbt file (Share .psbt sul telefono).
  3. Raccogli. Paste signed copy → Add signature. Oppure Scan signed QR (su macOS e Android) o il file firmato. Ogni copia si unisce alle altre, non le sostituisce. Una copia senza firme nuove viene rifiutata, con il motivo.
  4. Trasmetti. Al quorum: Review & Broadcast → Review signed transaction → Broadcast.

Su Liquid la transazione è un PSET. I passi sono gli stessi, QR compreso.

Una chiave segnata come USB hardware wallet firma dal computer: Sign with USB hardware wallet → Sign on device. Vedi Hardware wallet.

Firmare la spesa di un altro

  1. Apri. Send → Cosign a transaction. In WHICH CHAIN? scegli Bitcoin o Liquid.
  2. Carica. Paste, File o Scan QR (su macOS e Android), poi Load & Inspect.
  3. Controlla. Importi e indirizzi. Se qualcosa non torna, Decline.
  4. Firma. Sign & Export. Su computer c'è anche Sign with device.
  5. Restituisci. Show QR, Copy PSBT o il file. Su Liquid il pulsante dice Copy PSET.

Sul telefono. Qui firmi e basta: la trasmissione spetta a chi ha avviato la spesa. Ridagli la copia firmata.

Importo «unknown» o «UNVERIFIABLE amount — do not sign». La transazione nasconde quanto spende davvero e l'app non la firma. Avvisa chi te l'ha mandata.

Hardware wallet.

La chiave resta sul dispositivo: Templar prepara il pagamento, il dispositivo lo approva.

È facoltativo. Se usi solo wallet software, salta questo capitolo.

Quali dispositivi

DispositivoCollegamentoMonete
Ledger (Nano S / S Plus / X, Stax, Flex)USB su macOS, Windows e Linux. Driver integrato, HWI non serve.Solo Bitcoin
Blockstream JadeUSB su computer, driver integrato. Oppure QR, anche su Android.Bitcoin e Liquid via USB, solo Bitcoin via QR
SeedSigner e altri dispositivi air-gapQR con la fotocamera, su macOS e Android.Solo Bitcoin
Trezor, Coldcard, KeepKey, BitBox02USB su Windows e Linux, con lo strumento HWI. Non su macOS: la sandbox di sistema blocca HWI.Solo Bitcoin

Su Windows e Linux, se HWI manca, la schermata del dispositivo mostra il riquadro HWI toolkit required. Install HWI scarica la versione ufficiale e ne controlla lo SHA-256. Per Ledger e Jade non serve.

Prima di collegarlo

  • Ledger. Sbloccalo, apri l'app Bitcoin Testnet (non «Bitcoin») e chiudi Ledger Live.
  • Jade. Firmware aggiornato e testnet attiva, da Options → Settings → Device → Enable Testnet. Via USB chiudi Blockstream Green, perché la porta la usa un'app alla volta. Tieni il computer online: serve per lo sblocco con il PIN.
  • Jade via QR. Sbloccalo prima con l'app di Blockstream: Templar non fa da tramite per il PIN.

Creare il wallet

  1. Dove stanno le chiavi. Alla domanda Where do your keys live? scegli On a hardware wallet.
  2. Cavo o fotocamera. Alla domanda How does your device connect? scegli By cable (USB) o By camera (air-gapped QR). Su Android c'è solo la fotocamera.
  3. Segui i passi. Via USB: Connect your device → Confirm what this device will hold → Name your wallet. Via QR: Choose your device → Export descriptor → Paste descriptor & name. Alla fine Pairing summary mostra lo stato di ogni rete e i controlli fatti.

Attenzione. Con un dispositivo USB, in Receive il pulsante Verify on Ledger mostra l'indirizzo Bitcoin sullo schermo del dispositivo. Il nome resta quello anche con un Jade. L'indirizzo deve coincidere con quello dell'app, carattere per carattere. Se non coincide, fermati e segnalalo.

Firmare un invio

  • Via USB. In Send premi Sign on device. L'app accetta solo il dispositivo con l'impronta di questo wallet. Prima il dispositivo ti fa confermare un indirizzo del wallet. Poi mostra uscite e commissione, e tu approvi lì.
  • Via QR. Premi Export PSBT e l'app mostra la transazione come QR animato. Inquadralo con il dispositivo e approva. Riporta la copia firmata con Scan signed QR, con un file .psbt o incollandola. Prima di Broadcast l'app ti mostra cosa paga davvero. Solo Bitcoin.

La scansione dei QR c'è su macOS e Android. Su Windows e Linux i pulsanti di scansione non compaiono: incolla la copia o carica il file.

Liquid: solo Jade via USB

Jade è l'unico hardware wallet che firma Liquid, e solo via cavo. Se scegli Bitcoin + Liquid, la creazione guidata te lo ricorda: For Liquid, the device must be a Blockstream Jade. Con altri dispositivi il wallet nasce solo Bitcoin.

Hai creato un wallet Jade solo Bitcoin? Apri Wallet Info e premi Add Liquid from my Jade. Templar apre il Jade solo quando firmi, così tra un invio e l'altro Blockstream Green può usarlo.

Linux: permessi USB

Se compare il riquadro Device permissions needed, premi Fix device permissions: chiede la password una volta sola. Poi scollega e ricollega il dispositivo. La prima volta esci anche dalla sessione e rientra.

Nota. Con un hardware wallet la password dell'app è facoltativa, perché la chiave resta sul dispositivo. Protegge però il file del wallet su questo computer, con descriptor e chiavi pubbliche. Senza password il file resta in chiaro: chi legge i tuoi file vede saldo e storico, chi li modifica può cambiare gli indirizzi che Templar ti mostra.

10 — Avanzato

Liquid: asset, LiquiDEX e Peg.

Cosa fa la parte Liquid del wallet, oltre a ricevere e inviare.

Liquid è una sidechain di Bitcoin. Ha un blocco ogni minuto, transazioni confidenziali e asset che chiunque può emettere.

Queste schermate compaiono solo se il wallet ha Liquid. Per aggiungerlo a un wallet software: Wallet Info → Liquid Network → Enable Liquid. Usa la stessa frase di recupero, non c'è altro da annotare. Per un Jade vedi Hardware wallet.

Gli asset

La schermata Liquid elenca gli asset che hai, per esempio L-BTC. Il dettaglio di un asset mostra l'Asset ID con il pulsante Copy ID e, quando sono noti, Ticker, Precision e Domain.

  • Issue Asset crea un asset nuovo.
  • Reissue emette altre unità di un asset di cui hai il token di riemissione.
  • Burn distrugge unità dell'asset. Non si torna indietro.

Emettere un asset

  1. Define asset. Nome, ticker, precisione (da 0 a 8) e dominio, tutti obbligatori. Sono permanenti: dopo l'emissione non si cambiano.
  2. Initial supply. Quante unità emettere. Attiva Create reissuance token se vuoi poterne emettere altre più avanti. Senza token l'offerta resta fissa per sempre. Se perdi il token, non puoi più riemettere.
  3. Review & sign. Rileggi tutto e premi Sign & Issue.
  4. Il risultato. L'app mostra Asset ID, TxID e, se l'hai creato, l'ID del token di riemissione. Se compare Domain proof required, pubblica sul tuo dominio il file indicato: serve a registrare l'asset nell'explorer di Liquid testnet.

LiquiDEX

Un order book di swap atomici: due persone si scambiano asset in una sola transazione. Make offer pubblica una proposta, Take la accetta, Import proposal carica una proposta ricevuta. Le offerte segnate MAINNET · VIEW ONLY si possono solo guardare: il wallet firma solo su testnet.

Attenzione. LiquiDEX è sperimentale. La guida della alpha.14 segnala due problemi noti: un'offerta creata da te può non essere accettabile correttamente, e annullare un'offerta di token non riesce.

Peg

Peg-in porta BTC su Liquid come L-BTC. Peg-out fa il contrario. L'indirizzo di destinazione è già compilato con uno di questo wallet.

Attenzione. Il provider del peg è simulato: nessun fondo vero si muove. Lo ricorda la striscia gialla in cima alla schermata. L'app dice che un provider vero arriverà in un aggiornamento successivo.

Il peg ha bisogno di una parte Bitcoin. In un wallet solo Liquid il Peg non si può usare.

Ricevere e inviareSu Liquid l'indirizzo è confidenziale e si può riusare. Hardware walletLiquid su hardware: solo con un Jade via USB.

Collegare Templar Lend.

Templar Wallet firma i passi dei tuoi prestiti su un sito Templar Lend. Le chiavi restano nel wallet.

Il sito costruisce le transazioni del prestito. Templar te le mostra e firma solo dopo la tua conferma. A trasmetterle in rete è il sito, mai il wallet.

Nell'app il protocollo si chiama Templar Lend. I link iniziano con templar://.

Prima di iniziare

  • Installa nel modo giusto. Su Windows usa l'installer: lo zip portabile non registra i link templar://. Su macOS basta copiare l'app in Applicazioni dal .dmg. Su Linux servono i comandi qui sotto.
  • Imposta la password dell'app. Te la chiede prima di ogni firma. Su Mac, con Touch ID attivo, può bastare il dito.
  • Usa un wallet software con Liquid attivo. Hardware, watch-only e multisig non si collegano ancora.
  • Usa la rete del sito. Il wallet parte su Liquid Testnet. La rete si cambia in Settings › Network & Sync › Liquid network. Il cambio chiude il wallet aperto: riaprilo e sincronizza.

Solo Linux. Da un terminale aperto nella cartella estratta, questi comandi creano la voce nel menu e registrano i link templar://. Se sposti la cartella, ripetili.

mkdir -p ~/.local/share/applications
sed -e "s|^Exec=.*|Exec=$PWD/templar_wallet %u|" \
    -e "s|^Icon=.*|Icon=$PWD/templar_wallet.png|" \
    dev.templarwallet.templar_wallet.desktop \
    > ~/.local/share/applications/dev.templarwallet.templar_wallet.desktop
update-desktop-database ~/.local/share/applications
xdg-mime default dev.templarwallet.templar_wallet.desktop x-scheme-handler/squid

Collegare il wallet

  1. Parti dal sito. Nella pagina Wallet premi «Collega Templar Wallet».
  2. Templar si apre. Compare la schermata Connect wallet. Se l'archivio dei wallet è bloccato, prima ti chiede la password dell'app.
  3. Scegli il wallet. Templar propone solo quelli adatti.
  4. Leggi cosa riceve il sito. Una vista watch-only di Liquid: vede saldo e storico, non può spendere. La chiave escrow m/2121'/1'/0', un conto a parte usato solo nei contratti di prestito. Un indirizzo di ricezione e il nome del wallet.
  5. Conferma. Spunta la frase, premi Share with … e inserisci la password dell'app.
  6. Torna al sito. Compare Wallet connected. Open in browser ti riporta alla pagina, che si aggiorna da sola.

Niente di segreto lascia il computer.

Firmare un passo del prestito

La firma serve quando il prestito si apre, per le rate e il rimborso, in caso di default e di liquidazione.

  1. Apri la richiesta. Nella pagina del prestito premi «Firma con Templar Wallet».
  2. Confronta le due colonne. A sinistra What … says: ruolo, importi e durata come li racconta il sito. A destra What "…" reads: quello che il wallet legge nella transazione stessa.
  3. Firma. Spunta «I compared the site's summary with the wallet's reading…», premi Sign and send to … e inserisci la password.
  4. Fatto. Compare Signature sent. Quando tutte le parti hanno firmato, il sito trasmette la transazione. La pagina del prestito ne mostra l'id.
Nella colonna del walletVuol dire
escrow · your keyIl contratto del prestito chiede la tua firma.
your coinUna moneta tua.
not yours · contract · not yoursServe la chiave di qualcun altro.

Attenzione. Se le due colonne descrivono cose diverse, premi Cancel e segnalalo. Se nessun input porta una tua chiave, il pulsante resta spento: la richiesta è per un altro wallet.

Settings › Squid Protocol

Ci arrivi anche con un tocco dal pannello Liquid della Dashboard.

  • Status: la rete per cui il wallet è pronto, e Change network.
  • Open a request: incolla un link templar:// o, dove c'è la fotocamera, inquadrane il QR. È la via di riserva quando il sito non apre Templar.
  • Connected sites: chi vede un tuo wallet in sola lettura, e cosa ha ricevuto.
  • Signing history: le ultime 50 richieste, con l'esito. Clear history la svuota.
  • Preferred wallet for Squid requests: il wallet che risponde alle richieste e viene proposto per primo. Password e spunta servono comunque.
  • How it works: il riassunto in tre passi.

Nota. Forget cancella il sito solo da questo dispositivo. Il sito vede il wallet finché non lo rimuovi dal sito stesso. Questi dati restano qui e non contengono transazioni, importi o chiavi.

Per un problema con Templar Lend aggiungi la rete Liquid, il riferimento del prestito, il Request id e uno screenshot della schermata di firma con tutte e due le colonne.

Allega il log

Su computer il log è logs/templar.log nella cartella dati, più templar.log.1 se c'è. Per copiarlo sulla Scrivania, su macOS:

cp ~/Library/Containers/dev.templarwallet.templarWallet/Data/Library/Application\ Support/templar_wallet/logs/templar.log ~/Desktop/

Su Linux:

cp ~/.local/share/templar_wallet/logs/templar.log ~/Desktop/

Su Windows il log sta in %APPDATA%\templar_wallet\logs, o nella cartella scelta nell'installer. Su Android non si può esportare: manda screenshot, i passi fatti e l'ora approssimativa del problema.

Per vedere gli errori mentre accadono, su macOS avvia l'app dal Terminale:

"/Applications/Templar Wallet.app/Contents/MacOS/templar_wallet"

Su Linux avvia ./templar_wallet da un terminale aperto nella cartella estratta. Su Windows l'app non scrive nulla sulla console: copia il testo esatto dell'errore o fai uno screenshot.

Limiti noti

  • Solo testnet, nessun percorso verso la mainnet.
  • App solo in inglese. About mostra una versione sbagliata.
  • Scansione dei QR con la fotocamera solo su macOS e Android. Paste e File funzionano ovunque.
  • Niente USB su Android. Con un hardware wallet, Liquid funziona solo con Jade via USB.
  • Trezor, Coldcard, KeepKey e BitBox02 richiedono HWI su Windows e Linux. Su macOS non funzionano.
  • Nessuna schermata per alzare la commissione (RBF) di una transazione già inviata.
  • La password dell'app non si può cambiare né togliere.
  • LiquiDEX è sperimentale. Il Peg è simulato.
  • I wallet con regole personalizzate (policy) non sono ancora disponibili.
  • Una sola istanza dell'app per volta.
  • Niente notarizzazione Apple, niente certificato Authenticode, APK fuori dal Play Store: al primo avvio macOS, Windows e Android mostrano un avviso.

Prima di compilare

L'app è fatta di due pezzi che viaggiano insieme: la libreria Rust e il pacchetto Flutter. Se all'avvio la libreria manca, l'app di release si ferma su una schermata di errore.

Ogni sistema si compila su quel sistema: Flutter desktop non fa cross-compilazione. Ti servono:

  • Rust stable (edition 2021), da rustup.rs.
  • Flutter 3.44.1 stable, con Dart ^3.12.0.

I comandi partono dalla radice del repository, dove c'è Cargo.toml. La prima build Rust compila circa 500 crate e richiede alcuni minuti.

macOS

Serve Xcode con gli strumenti da riga di comando (xcode-select --install).

cd src/templar_wallet
flutter pub get
flutter build macos --release
open build/macos/Build/Products/Release/templar_wallet.app

Non serve altro: una fase Run Script di Xcode compila libwallet_ffi.dylib e la mette nell'app.

Vuoi che la tua build giri anche sui Mac Intel? Prima aggiungi i target: rustup target add x86_64-apple-darwin aarch64-apple-darwin.

Per un DMG lancia ./scripts/make_dmg.sh dalla radice. Il file finisce in dist/.

Linux

Su Debian o Ubuntu, dalla 22.04 in poi, installa i pacchetti:

sudo apt update
sudo apt install -y build-essential clang cmake ninja-build pkg-config \
    libgtk-3-dev libssl-dev libudev-dev curl git unzip xz-utils zip
flutter config --enable-linux-desktop

Non saltare libudev-dev. Senza, la build riesce lo stesso, ma l'app non riconosce mai una Jade.

Poi compila, copia la libreria accanto all'eseguibile e avvia:

cargo build --release -p wallet-ffi
cd src/templar_wallet
flutter pub get
flutter build linux --release
cp ../../target/release/libwallet_ffi.so build/linux/x64/release/bundle/lib/
./build/linux/x64/release/bundle/templar_wallet

Si distribuisce tutta la cartella bundle/. Sul computer di arrivo serve GTK 3, e una glibc non più vecchia di quella del computer che ha compilato.

Fedora e altri dettagli: LinuxBuild.md.

Windows

Installa prima:

  • Visual Studio 2022 con il carico di lavoro Desktop development with C++. VS Code da solo non basta.
  • Git for Windows.
  • Rust con rustup-init.exe, toolchain stable-x86_64-pc-windows-msvc.

OpenSSL non serve. In PowerShell, dalla radice del repository:

flutter config --enable-windows-desktop
flutter doctor
cargo build --release -p wallet-ffi
cd src\templar_wallet
flutter pub get
flutter build windows --release
Copy-Item ..\..\target\release\wallet_ffi.dll build\windows\x64\runner\Release\
.\build\windows\x64\runner\Release\templar_wallet.exe

flutter doctor deve mostrare Visual Studio in verde.

Si distribuisce tutta la cartella Release\. Su un PC senza Visual Studio può servire anche il VC++ Redistributable.

L'installer si crea con Inno Setup 6, dalla radice:

ISCC.exe /DMyAppVersion=<versione> packaging\windows\templar-wallet.iss

Altri dettagli: WindowsBuild.md.

Con uno script solo

Su Linux e Windows uno script fa tutto, con gli stessi passi della build automatica.

SistemaComandoTi servePrima volta
Linux x64bash scripts/build_linux.shDocker o Podmancirca 15 GB, circa un'ora
Windows 10/11 x64doppio clic su scripts\build_windows.cmdniente: propone di installare ciò che mancacirca 25 GB, un'ora o più

Lo script Linux lavora in un'immagine Ubuntu 22.04, qualunque distribuzione tu usi. Altri dettagli: HELPER_BUILDS.md.

Android

Serve l'SDK Android con l'NDK 28.2.13676358 e Flutter con la toolchain Android.

rustup target add aarch64-linux-android x86_64-linux-android
cargo install cargo-ndk
./scripts/build_android.sh --release

Esce un APK per architettura in src/templar_wallet/build/app/outputs/flutter-apk/: app-arm64-v8a-release.apk per i telefoni, app-x86_64-release.apk per l'emulatore.

Su Android restano fuori gli hardware wallet USB: per firmare fuori dal telefono c'è il QR. Per ora anche la release è firmata con la chiave di debug.

Test e sviluppo

cargo test -p templar-core -p wallet-ffi
cargo clippy --workspace -- -W clippy::all
cargo fmt --all
cd src/templar_wallet
flutter analyze --no-fatal-infos
flutter test
flutter run -d macos

I test Rust girano offline, in una decina di secondi. Con flutter run scegli -d macos, -d linux o -d windows.

Queste variabili d'ambiente cambiano alcune scelte all'avvio, senza ricompilare:

VariabileCosa cambia

TEMPLAR_LIQUID_ELECTRUM_URLIl server Electrum per Liquid.
TEMPLAR_DATA_DIRLa cartella dei dati.
TEMPLAR_HWI_BINIl programma hwi da usare per gli hardware wallet.

Build automatiche

Il workflow build-desktop parte a ogni push su un ramo build-*, a ogni tag v* o a mano. Prima girano i test: una build rotta non arriva ai pacchetti.

macOS e Android si compilano sul Mac del progetto. Linux (Ubuntu 22.04) e Windows sui runner di GitHub: quando i minuti gratuiti finiscono, si usano gli script. Con un tag v* i pacchetti finiscono in una release in bozza.

Demo locale del protocollo

Facoltativa. Gira su regtest, una catena privata sul tuo computer. Nel repository del protocollo lancia:

cargo run -p squid-ops -- up
set -a; . data/regtest/regtest.env; set +a
cargo run -p squid-lend-server

La prima volta up scarica elementsd.

  1. Apri il sito. Risponde su http://127.0.0.1:8087.
  2. Passa Templar su regtest. Vai in Settings › Network & Sync › Liquid network, scegli Regtest e premi Apply. Il wallet aperto si chiude: riaprilo e sincronizza.
  3. Ricevi monete di prova. Sempre nel repository del protocollo: cargo run -p squid-ops -- fund <indirizzo> 1.0, con un indirizzo Liquid regtest di Templar.
  4. Collega il wallet. Sul sito premi Collega Templar Wallet. Se il link non apre l'app, incollalo in Settings › Squid Protocol › Open a request. Il resto funziona come in Collegare Templar Lend.
